================================================================================
                        API ENDPOINTS (7)
================================================================================

1. POST /api/models/validation/validate
   Validate response with Claude

2. POST /api/models/validation/score
   Score quality (1-10)

3. POST /api/models/validation/compare
   Compare multiple models

4. GET /api/models/validation/performance/{modelName}
   Get individual model report

5. GET /api/models/validation/performance/all
   Get all models report

6. POST /api/models/validation/record
   Record metrics

7. POST /api/models/validation/clear
   Clear session metrics
